# Найденные баги: 5 — все исправлены

Код, сгенерированный по [спецификации](SPEC-mdlinkcheck.md) за один промпт,
проверен отдельным ревью-агентом. Найдено 5 дефектов, каждый воспроизведён
экспериментально.

**Число 5 — это метрика замера** качества one-shot генерации, она зафиксирована
как есть. Исправления сделаны **вторым проходом**, уже после замера, поэтому
метрику не искажают. На каждый дефект добавлен регрессионный тест
(`tests/test_regressions.py`), тестов стало 37 вместо 31.

## Детали

**1. Необработанный `httpx.InvalidURL`** — `checker.py:53-62`
Ловятся только `TimeoutException`/`HTTPError`, а `InvalidURL` наследуется от `Exception`.
Ссылка `[a](https://example.com:abc/)` → трейсбек вместо BROKEN. Исключение всплывает
через `asyncio.gather`, поэтому одна битая ссылка убивает проверку всех остальных.
По спеке: «таймаут или ошибка сети → BROKEN».

**2. Необработанные исключения `Path.resolve()`** — `checker.py:40`, вызов из `checker.py:47`
`ValueError`/`RuntimeError` не ловятся ни здесь, ни в `cli.py:78` (там только `OSError`).
`[a](./x%00y.md)` → `ValueError: embedded null character`. Самозацикленный симлинк →
`RuntimeError: Symlink loop`. Оба сценария реальны для чужого клонируемого репозитория.

**3. `os.walk` без `onerror`** — `scanner.py:16`, `cli.py:66-71`
Папка без прав на чтение: `exists()` = True, обход пуст → «Все ссылки рабочие: 0 из 0»,
**exit 0**. Ложноположительный вердикт вместо требуемого спекой кода 2 при «нет прав».
Нечитаемая подпапка внутри дерева молча теряет свои `.md` файлы.

**4. Необработанный `subprocess.TimeoutExpired`** — `repo.py:44-50`
`timeout=300` есть, но исключение не является ни `CloneError`, ни `OSError`.
Долгий клон → трейсбек и exit 1 вместо требуемого спекой кода 2.

**5. Отсутствует `rich.markup.escape`** — `report.py:37-44`
Имя файла и примечание вставляются в таблицу без экранирования. Файл `x[/b].md`
→ `MarkupError`, падение и `--report` не пишется.

## Что проверено и багом НЕ является

Относительные пути (`./x`, `../x`, папка, `#anchor`, `?query`, `%20`, литеральный `%`,
`file://`), номера строк во всех типах блоков, таймауты и `GIT_TERMINAL_PROMPT=0`,
HEAD 405 → GET, дедупликация URL, семафор на 10, SKIPPED вне знаменателя,
коды возврата 0/1/2, создание `--report` при нуле сломанных — всё корректно.

Все 5 дефектов — необработанные краевые случаи, а не расхождения в основной логике.
