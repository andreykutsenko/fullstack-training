# mdlinkcheck

> 📊 **Результат эксперимента** (сколько промптов, токенов, багов, стоимость,
> скриншоты прогона) — в отдельном файле **[REPORT.md](REPORT.md)**.

CLI-утилита: рекурсивно находит `.md` файлы, извлекает из них ссылки и проверяет,
что локальные файлы существуют, а внешние URL отвечают по HTTP.

## Установка

```bash
python3 -m venv .venv          # или: uv venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Python 3.11+. Зависимости: `markdown-it-py`, `httpx`, `rich`; для тестов `pytest`, `respx`.

## Запуск

```bash
python -m mdlinkcheck <путь-или-URL> [--broken-only] [--report FILE] [--timeout N]
```

Примеры:

```bash
python -m mdlinkcheck ./tests/fixtures
python -m mdlinkcheck ./docs --broken-only --report broken.md
python -m mdlinkcheck https://github.com/user/repo/tree/main/docs
echo $?
```

Аргумент, начинающийся с `http`, считается URL репозитория: он клонируется
`git clone --depth 1` во временную папку, сканируется и удаляется. Форма
`.../tree/<branch>/<subdir>` понимается: клонируется ветка `<branch>`,
сканируется подпапка `<subdir>`. Перед вызовом git выставляется
`GIT_TERMINAL_PROMPT=0`, поэтому на приватном репозитории команда не зависает
на запросе пароля, а завершается с кодом 2.

### Опции

| Опция | Смысл |
| --- | --- |
| `--broken-only` | в таблице показывать только сломанные ссылки (вердикт считается по всем) |
| `--report FILE` | записать markdown-отчёт о сломанных ссылках; файл создаётся всегда, даже если сломанных нет — с явной пометкой |
| `--timeout N` | таймаут HTTP-запроса в секундах, по умолчанию 10 |

### Коды возврата

| Код | Значение |
| --- | --- |
| 0 | сломанных ссылок нет |
| 1 | есть сломанные ссылки |
| 2 | ошибка: путь не найден, клон не удался, нет прав |

## Как это работает

**Поиск файлов.** Рекурсивный обход, папки `.git`, `node_modules`, `.venv`,
`__pycache__` пропускаются.

**Извлечение ссылок.** Разбор через `markdown-it-py` (`commonmark`) с обходом
токенов: `href` из `link_open`, `src` из `image`. Регулярками текст не парсится,
поэтому ссылки внутри блоков кода не попадают в результат. `md.validateLink`
переопределён на `lambda url: True` — иначе markdown-it молча выбрасывает
`file://` ссылки. Референсные ссылки и автоссылки разворачиваются самим
парсером в те же токены. Голые URL в тексте не ищутся. Для каждой ссылки
запоминается файл и номер строки блочного токена (`map[0] + 1`).

**Локальные ссылки.** Отбрасываются `#якорь` и `?query`, путь декодируется
`unquote` и резолвится от папки файла, в котором ссылка найдена. Схема `file://`
трактуется как абсолютный путь ОС через `urllib.request.url2pathname`.
Существующий файл или папка → OK, иначе BROKEN.

**Внешние ссылки.** `httpx`, таймаут 10 с, редиректы разрешены, браузерный
`User-Agent` (дефолтный UA httpx блокируется Cloudflare и GitHub кодом 403).
Сначала `HEAD`; если код ответа ≥ 400 — повтор через `GET`, берётся его
результат (многие серверы штатно отвечают на HEAD кодами 405/403). 2xx/3xx → OK,
4xx/5xx → BROKEN с кодом, таймаут или сетевая ошибка → BROKEN. Одинаковые URL
запрашиваются один раз, параллельно, не более 10 одновременно.

**SKIPPED.** Схемы `mailto:`, `tel:` и чистые `#якоря` пропускаются и не входят
в знаменатель вердикта.

## Принятые решения по неоднозначностям ТЗ

- **Прочие схемы** (`ftp:`, `data:`, `javascript:` и т. п.) — статус SKIPPED,
  как и `mailto:`/`tel:`: проверять их нечем, в знаменатель они не входят.
- **Путь-файл вместо папки.** Если позиционный аргумент указывает на `.md` файл,
  проверяется он один; на файл другого расширения — ссылок не найдено.
- **`--broken-only`** влияет только на таблицу; строка вердикта всегда считается
  по всем проверенным ссылкам.
- **Ссылка на существующую папку** (`[a](./docs)`) считается рабочей.
- **Якорь внутри файла не проверяется**: `./page.md#section` — OK, если
  существует `page.md`; наличие самого заголовка не валидируется.
- **Клонирование в форме `/tree/<branch>`**: если после ветки указана подпапка,
  сканируется только она; отсутствие подпапки в репозитории — ошибка с кодом 2.
- **Цвет** отключается, когда stdout не терминал (`rich` `no_color`).

## Тесты

```bash
pytest
```

Сеть в тестах не используется: HTTP мокается через `respx`, локальные случаи
собираются во временных папках. Фикстура с заведомо битыми ссылками —
`tests/fixtures`.
